# YKS MASTER

YKS sınavına hazırlanırken günlük çalışma planımı ve ilerlememi takip etmeme yardımcı olacak bir web uygulaması geliştirmeyi planlıyorum. Projemde TYT/AYT ders ve konu seçimi, günlük plan oluşturma ve haftalık çalışma özeti gibi özellikler hedefliyorum.

## Proje durumu

Bu çalışma şu anda proje önerisi aşamasındadır. Uygulamanın kodlamasına henüz başlanmadı; yukarıda yazanlar planlanan özelliklerdir.
